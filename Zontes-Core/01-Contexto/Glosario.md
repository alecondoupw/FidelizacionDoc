# Glosario

| Término | Sentido en Zontes | No confundir con |
| --- | --- | --- |
| Marca | Zontes, Kiden o NIU; separa reglas, beneficios, contenido y reportes | Rol de usuario |
| Cliente vinculado | Cuenta nueva unida por correo normalizado a registro preexistente | Administrador |
| Cliente no vinculado | Cuenta sin coincidencia en base existente | Cuenta inválida |
| Evento válido | Compra/referido/mantenimiento/asistencia confirmado por fuente autorizada | Clic del usuario |
| Regla de puntos | Evento + marca + cantidad + activo/inactivo, sin condiciones extras | Movimiento histórico |
| Movimiento | Entrada/salida/vencimiento de puntos auditable | Saldo agregado mutable |
| Lote de puntos | Unidad conceptual con fecha de otorgamiento/vencimiento para gastar/expirar | Regla futura |
| Canje | Consumo autorizado de puntos por un beneficio | Premio sin control de stock |
| Administrador inicial | Cuenta precreada por mecanismo seguro | Registro público de admin |
| ID token | Credencial Firebase del usuario que Express verifica | Clave de servicio del Admin SDK |
