# Entorno local y repositorios

`E:/Repositorios/Hackathon/Zontes/Zontes-Core` es el baúl documental. `FE_REPO` y `BE_REPO` son **frentes separados**, todavía sin rutas elegidas ni repositorios operativos verificados. Paulo indicó que se le pedirán las ubicaciones y la organización Git **al iniciar F0, no ahora**. La organización definitiva (dos repos Git o dos paquetes) depende de DEC-01. No registrar aquí claves de Firebase, credenciales, tokens, correos reales ni .env. No asumir comandos de build, deploy o test hasta que existan package manifests. Ver [[05-Desarrollo/Lote F0 - instalacion separada frontend y backend]].

Al crear entornos: registrar rutas precisas, ramas/revisiones, versiones efectivas, procedimientos de instalación aprobados, emuladores/proyectos de prueba, variables por **nombre** y custodio, nunca valores. Separar desarrollo, prueba y producción si se aprueba infraestructura. Ver [[02-Arquitectura/Decisiones pendientes]] y [[05-Desarrollo/Ramas y entregas]].
