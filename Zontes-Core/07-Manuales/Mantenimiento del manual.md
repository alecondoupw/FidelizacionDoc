# Mantenimiento del manual

Actualizar [[07-Manuales/Manual de usuario]] al cambiar un flujo o UI-ID aprobado, no sólo al terminar F7. Registrar revisión FE/BE, fecha, responsable, capturas anonimizadas y prueba de que el paso reproduce el comportamiento. Si cambia una regla, enlazar [[04-Reglas-de-negocio/_Indice de reglas]] y la decisión aplicable. Una pantalla propuesta no autoriza documentarla como existente.
