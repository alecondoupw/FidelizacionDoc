# Manual de usuario — estructura pendiente

No hay producto funcional; este manual es un índice de escritura futura, no instrucciones verificadas. Preparar apartados separados para cliente (acceso/vínculo, puntos, vencimientos, catálogo y canje) y administrador (usuarios, reglas, beneficios, reportes, exportación y contenido). Cada paso debe referir UI-ID, rol, estado esperado, error frecuente y revisión de la aplicación donde se verificó. Evitar capturas con datos reales.
