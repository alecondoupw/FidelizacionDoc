# Contrato de agentes — Zontes

Este directorio aloja `Zontes-Core/`, memoria canónica del proyecto. Entrar por `Zontes-Core/00-Inicio.md`; leer `01-Contexto/Contexto activo.md`, el lote y sólo las notas necesarias. Aplicable a Codex y a cualquier agente que lea AGENTS.md.

- Distinguir requisito de PDF, propuesta, decisión de Paulo, código implementado y prueba ejecutada.
- Base estructural `CORES/nextjs+nestjs`; stack propuesto real en PDF: Next.js + Express + Firebase. No introducir NestJS por herencia.
- Planear FE_REPO y BE_REPO como líneas separadas; rutas y formato pendientes de DEC-01. No crear repos, conectar servicios, instalar skills/MCP ni desplegar por inferencia.
- Antes de variar arquitectura, proveedor, alcance, permisos, datos, rutas o contenido ejecutable, consultar al propietario. No usar datos ni credenciales reales sin autorización.
- Documentación persistente y evidencia de este proyecto van en `Zontes-Core/`; código de producto sólo en repositorios operativos cuando existan y se solicite.
- Toda UI debe cumplir mapa de vistas y criterios visuales, con contrato BE, estados y pruebas. No presentar mock como producto verificado.
- Ahorrar contexto leyendo índices/archivos pertinentes y entregando paquetes de trabajo acotados; verificar el resultado antes de afirmar cierre.
